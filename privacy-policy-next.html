DealScan — Privacy Policy

Last updated: November 1, 2026

DealScan is a browser extension that evaluates Facebook Marketplace listings using the Anthropic (Claude) API. This policy explains what data the extension handles and how.

The short version

By default, DealScan has no servers of its own and sends nothing to the developer. It stores data only in your browser. It connects to two outside services: the Anthropic API, using an API key you provide, and Facebook's image servers, to download listing photos. An optional server mode changes this, as described under "Server mode". It is off unless you turn it on.

What is read from the page

On a Marketplace listing, with the side panel open, the extension reads the listing's title, price, condition, description, location, year and mileage (where shown), photo addresses, and the page address. Reading the listing does not send it anywhere. If no structured description is available, the extension uses the longest block of text on the page as the description, which could include other text from the page.

To confirm it is reading the right listing, the extension reads the listing ID from links on the listing's page and ignores the rest of those links. These links can point to the seller's profile, but the extension does not read, store, log, or send the seller's profile ID. It also compares the listing's title and price with the page title and with any search result for the same listing on the page. These checks stay in your browser.

The extension's scripts load on all facebook.com pages so they can detect when you move to a listing without a page reload. On other pages they check only the page address and do not read page content.

What is sent to Anthropic

When you start an evaluation, the extension sends the Anthropic API (api.anthropic.com):

  • The listing's title, price, condition, location, year and mileage (where available), and the start of its description, plus a category worked out by the extension.
  • Up to three listing photos, if photo analysis is on. It is on by default and can be turned off in the options.
  • Your API key, to authenticate the request. It is not sent to anyone else.

Nothing is sent when you only browse listings, when the extension can't read a listing, or when a cached result is shown.

Seller information. Starting with version 1.3.0, the extension does not read the seller's name from the listing's data. Published versions up to and including 1.2.1 read the seller's name from the page but did not send it to Anthropic or save it. No published version reads the seller's profile link. Text and photos are sent as they appear in the listing, so if a seller's name appears in the description or in a photo, it is included.

Web search. This is off by default. If you turn it on in the options, Claude can run web searches on Anthropic's side to look up prices.

Server mode

If you choose server mode in the options and enter a server address and token, the extension sends evaluations to that DealScan server instead of straight to Anthropic. The server sends them to Anthropic using its own API key. This section applies only when you turn server mode on.

  • Sent to the server: the listing ID, title, price, condition, category, description, location, year and mileage where available, up to three photos if photo analysis is on, the model chosen, and your token.
  • Stored by the server: the listing ID, title, price, condition, category, and description; each evaluation's result, outcome, reason if it failed, model, prompt version, token counts, time taken, and cost; which token made the request; and a hash of your token and a name for it. A description can contain anything the seller wrote.
  • Not stored by the server: photos, the listing's location, and the page address.
  • Never sent to the server: the seller's name or profile link as fields, and your Anthropic API key if you have one saved. The server rejects requests with fields it doesn't recognize, and it never contacts Facebook.

Whoever runs that server controls this data, and it is subject to their practices. In server mode, the extension asks for permission to reach the address you enter. Web search isn't available in server mode.

What is stored in your browser

  • Settings (chrome.storage.local): your API key, model choice, the photo and web search options, and the mode, server address, and token if you use server mode.
  • Saved history (chrome.storage.local): for evaluations you choose to save, an ID generated by the extension, the date saved, the listing address, title, category, price, currency, score, verdict, recommendation, suggested offer, and summary, plus a record of the evaluation: the model, prompt version, token counts, number of web searches and attempts, time taken, and calculated cost. You can remove entries, clear history, or export it as a file from within the extension.
  • Usage log (chrome.storage.local): for each billed evaluation, whether or not you save it, the time, outcome, reason if it failed, model, prompt version, token counts, number of web searches and attempts, time taken, and calculated cost. It contains no listing content. You can export it or clear it from the extension's options.
  • Temporary results (chrome.storage.session): recent results, keyed by listing address, so reopening a listing doesn't repeat the request. These are cleared when the browser closes.

None of this is synced to your Google account.

Third-party processing

Data sent to the Anthropic API is processed by Anthropic, PBC to provide the evaluation. Anthropic's handling of that data is governed by its own policies, available at anthropic.com/legal/privacy.

What we do NOT do

  • We do not operate any servers or databases.
  • We do not collect, see, or store your data.
  • We do not sell or share your data with anyone.
  • We do not use your data for advertising, profiling, or any purpose other than producing the evaluation you request.

Permissions

The extension requests:

  • Access to facebook.com pages, to read listings and show the Evaluate button.
  • Access to Facebook's image servers (fbcdn.net), to download listing photos.
  • Access to the Anthropic API, to send your evaluation request.
  • Optional access to a server address you enter, requested only if you turn on server mode.
  • storage, for your settings, history, and temporary results.
  • sidePanel, for its interface.
  • scripting, to load its scripts into a listing tab that was already open.
