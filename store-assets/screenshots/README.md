# DealScan — Chrome Web Store image assets

Drop original screenshots in `raw/`. Store-ready copies land here in this folder.

## Chrome Web Store image specs

| Asset                | Size (px)   | Format          | Notes                          |
|----------------------|-------------|-----------------|--------------------------------|
| Screenshot           | **1280×800** (or 640×400) | PNG or JPEG (24-bit, no alpha) | 1–5 allowed. 1280×800 preferred. |
| Small promo tile     | 440×280     | PNG or JPEG     | Optional but recommended.      |
| Marquee promo tile   | 1400×560    | PNG or JPEG     | Optional.                      |
| Store icon           | 128×128     | PNG             | Already shipped in the extension. |

## Suggested 5 screenshots
1. Verdict panel on a real listing (the score ring + price breakdown) — the hero shot.
2. The floating "⚡ Evaluate Deal" button on a Marketplace listing.
3. History tab with a few saved evaluations.
4. Options page (API key + model + settings).
5. A "Great Deal" vs an "Overpriced" verdict side-by-side, or a second strong verdict.

## Notes on sizing
Store screenshots must be **exactly** 1280×800. Browser screenshots are usually a wider
aspect ratio, so each image is either cropped to the relevant UI or fitted onto a
1280×800 canvas with a background — decided per image.
